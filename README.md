# exam-scanner-60
Scanner Lembar Jawaban Komputer dengan konfigurasi maksimal 60 soal. Lengkap dengan upload kunci jawaban dan deteksi hasil.

Cara Install :
1. Install seluruh kebutuhan teknis meliputi Python IDE, library dan Framework Streamlit. Seluruh requirement dapat dilihat di file requirements.txt
2. Jalankan app.py (Lihat sumber kode dan dokumentasi Streamlit)

Cara Kerja : 
1. Download dan Print Template Lembar Jawaban
2. Download Template Kunci Jawaban
3. Upload kunci jawaban
4. Lakukan scanning dengan kamera/file upload
